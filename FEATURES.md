# Meowy feature snapshot
JavaScript / discord.js v14 rewrite.

Implemented in this initial rewrite:
- Core: ping, echo, coinflip, color.
- Discord utilities: avatar, userinfo, guildinfo.
- Groq chat.
- Minecraft UUID and server lookup; Roblox username lookup.
- GitHub profile/repository, Urban Dictionary.
- Last.fm recent/top, Spotify search.
- Public-profile link helpers for Instagram, TikTok, X and Telegram.

Build and runtime validation still need to be performed. OCR/transcription and many planned commands are not yet implemented.
